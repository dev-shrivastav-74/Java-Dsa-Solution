Two Sum mein hum HashMap ko number → index ke form mein use karte hain. Pehle array ke har number ko check karte hain aur target - current number karke result nikalte hain, yani hume doosra kaunsa number chahiye. Phir containsKey(result) se check karte hain ki woh required number HashMap mein pehle se present hai ya nahi. Agar present hai toh get(result) se us number ka index mil jaata hai, kyunki humne HashMap ki value mein index store kiya tha. Phir us index aur current i ko ek int[] array mein return kar dete hain. Agar required number nahi mila, toh put(nums[i], i) se current number ko key aur uske index ko value bana kar HashMap mein store kar dete hain. Isliye ye approach O(n) time mein kaam karti hai.
